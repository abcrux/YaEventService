# YaEventService

REST API для управления событиями. 
Учебный проект на ASP.NET Core для курса по C#.

## Требования

- [.NET SDK 8.0](https://dotnet.microsoft.com/download/dotnet/8.0) или выше
- Любой терминал

Проверить установку:

```bash
dotnet --version
```

Версия должна быть  `8.0.x` или выше.

## Запуск

1. Клонировать репозиторий:

   ```bash
   git clone <URL-репозитория>
   cd YaEventService
   ```

2. Запустить приложение:

   ```bash
   dotnet run
   ```

3. В консоли появится строка вида:

   ```
   Now listening on: http://localhost:5211
   ```

   Запомнить порт - он понадобится для запросов.

## Проверка работоспособности

Открыть в браузере:

```
http://localhost:5211/events
```

Должен вернуться пустой массив:

```json
[]
```

Если отображается `[]` - API работает.

## Эндпоинты

| Метод | URL | Описание |
|---|---|---|
| GET | `/events` | Список всех событий |
| GET | `/events/{id}` | Событие по id, 404 если не найдено |
| POST | `/events` | Создать событие, 201 в случае успеха |
| PUT | `/events/{id}` | Обновить событие, 404 если не найдено |
| DELETE | `/events/{id}` | Удалить событие, 404 если не найдено |

### Пример запроса на создание

```bash
curl -X POST http://localhost:5211/events \
  -H "Content-Type: application/json" \
  -d '{
    "title": "Концерт кавер-групп",
    "description": "Лучшие кавер-группы Москвы",
    "startAt": "2026-10-05T19:00:00",
    "endAt": "2026-10-05T22:00:00"
  }'
```

Ожидаемый ответ - `201 Created` с созданным объектом, включая присвоенный `id`.

## Тестирование запросов

Все запросы лежат в файле `YaEventService.http`. Открыть его в VS Code с расширением [REST Client](https://marketplace.visualstudio.com/items?itemName=humao.rest-client) - над каждым запросом появится кнопка **Send Request**.

## Swagger

При запуске в окружении Development доступен Swagger UI:

```
http://localhost:5211/swagger
```

Там можно посмотреть все эндпоинты и отправить тестовые запросы прямо из браузера.

├── Contracts/           DTO и маппинг
├── Controllers/         HTTP-эндпоинты

## Хранение данных

События хранятся **в памяти** - при перезапуске приложения данные очищаются. Это временное решение для учебного проекта.
